---
description: Roz ki ek viral-style Hindi reel (random style, plan → preview → render)
---
1. `.agents/skills/reel-animation-styles/SKILL.md` aur `resources/styles.md` padho.
2. `out/` folder mein pichhli reel ka style dekho; usse alag style random chuno.
3. कथा और रहस्य ke liye 3 topic ideas do (pauranik katha, Uttarakhand, itihaas, rahasya) aur user se ek chunwao.
4. 5–8 beat plan dikhao, OK milne par `reels/<slug>/reel.html` likho.
5. `node .agents/skills/reel-animation-styles/scripts/render.mjs reels/<slug>/reel.html out/<slug>.mp4 --preview 1,5,10,15`; stills check karke galti theek karo.
6. Poora render karo; Hindi title, description aur 5 hashtags do.
